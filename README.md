# summer-modis-chla-2026

项目背景

本项目是本人利用2026年暑期进行的个人研究项目，旨在掌握遥感数据处理与Python数据分析技能，为下学期去中国海洋大学交换学习，进刘阳教授课题组锻炼（渔业遥感与智慧渔业方向）做准备。

研究区域聚焦福建省厦门湾及周边海域（117°E–119°E, 23°N–25°N），利用NASA Aqua MODIS卫星的Level-3叶绿素a浓度产品，分析2024年夏季（6–8月）该海域叶绿素a的时空分布特征及其与环境因子（海表温度、风场）的关系。
